Student Management System

A beginner-friendly Python Student Management System that reads student information from a JSON file and provides different operations through a menu-driven program.

📌 Project Overview

This project is created using Python to practice:

JSON file handling

for loops

while loops

if, elif, else

break

continue

pass

Searching data

Calculating student results

Finding highest and lowest scorers

The student information is stored in a students.json file.
